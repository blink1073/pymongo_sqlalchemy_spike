## Getting Starting

The wheels for PyMongoSqlTranslate and PyMongoSchemaBuilder are in the wheels folder.

You can install them with pip. You will probably need to install them from the sample notebook folder if you want to use the existing notebook if you need them in the notebook.

```sh
# Install py_mongosqltranslate
pip install ./wheels/py_mongosqltranslate-0.1.0-cp313-cp313-macosx_11_0_arm64.whl

# Install py_mongoschemabuilder
pip install ./wheels/py_schema_builder_library-0.1.0-cp313-cp313-macosx_11_0_arm64.whl
```

The Python Notebook has a .venv with it. You can install the requirements.txt and then open the notebook with:
```sh
jupyter notebook
```
